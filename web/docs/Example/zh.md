# 示例节点

简要描述此节点的作用。

## 输入

| 参数             | 类型   | 描述                |
|------------------|--------|---------------------|
| `image`          | IMAGE  | 要处理的输入图像    |
| `int_field`      | INT    | 一个整数参数        |
| `float_field`    | FLOAT  | 一个浮点参数        |
| `string_field`   | STRING | 一个文本输入        |
| `print_to_screen`| select | 启用/禁用控制台输出 |

## 输出

| 输出    | 类型  | 描述                |
|---------|-------|---------------------|
| `IMAGE` | IMAGE | 处理后的输出图像    |
