# Prompt List

一个用于 ComfyUI 的自定义节点集合

## 快速开始

1. 安装 [ComfyUI](https://docs.comfy.org/get_started)。
2. 安装 [ComfyUI-Manager](https://github.com/ltdrdata/ComfyUI-Manager)
3. 在 ComfyUI-Manager 中查找此扩展。如果你要手动安装，请将此仓库克隆到 `ComfyUI/custom_nodes` 下。
4. 重启 ComfyUI。

# 功能

- "字符串列表" (主要指提示词字符串的列表) 的若干方法
  - 创建
  - 取值
  - 修改
  - 遍历
